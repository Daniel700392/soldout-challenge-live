# SoldOut Challenge Live

Sistema distribuido de venta de boletos en tiempo real basado en microservicios.

## Arquitectura

- API Gateway
- Booking Service
- Inventory Service
- Payment Service
- Notification Service

## Tecnologías

- Node.js
- Docker
- Kubernetes
- Prometheus
- Grafana

## Equipo

Proyecto académico orientado a resiliencia, concurrencia y alta disponibilidad.
